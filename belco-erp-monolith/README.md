# نظام بيلكو ERP (Full-Stack Monolith - Next.js)

هذا هو النسخة المتكاملة (Monolith) لمشروع **بيلكو ERP**، حيث تم دمج الواجهة الأمامية والباك اند في تطبيق Next.js واحد لتسهيل رفعه وتشغيله أونلاين بضغطة زر واحدة.

## خطوات التشغيل والرفع السريع (Vercel):
1. ارفع هذا المجلد بالكامل إلى مستودع على **GitHub**.
2. ادخل على منصة **Vercel** واضغط **Add New Project** واختار المستودع.
3. اضغط **Deploy** ولن تحتاج أي إعدادات معقدة؛ سيتم نشر الموقع فوراً وتحصل على رابط مباشر تعمل عليه من أي موبايل أو كمبيوتر!
